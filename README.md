# REST API Event Project

## Назначение проекта

Учебный проект на **ASP.NET Core Web API**, реализующий базовый
REST‑сервис для управления мероприятиями (Events).\
Сервис предоставляет стандартные CRUD‑операции:

-   создание события
-   получение списка событий
-   получение события по id
-   обновление события
-   удаление события

На текущем этапе данные хранятся **в памяти приложения** (in‑memory).
Архитектура разделена на контроллеры, сервисы, DTO и мапперы, что
позволяет в дальнейшем легко заменить хранилище на базу данных.

------------------------------------------------------------------------

## Используемые технологии

-   .NET 10
-   ASP.NET Core Web API
-   Swagger (Swashbuckle.AspNetCore)

------------------------------------------------------------------------

## Зависимости

Основные NuGet‑пакеты:

-   `Microsoft.AspNetCore.App`
-   `Swashbuckle.AspNetCore`

Swagger используется для автоматической генерации документации и
тестирования API. **Подключен и работает только в Development**

------------------------------------------------------------------------

## Сборка проекта

``` bash
dotnet build
```

------------------------------------------------------------------------

## Запуск приложения

``` bash
dotnet run
```

После запуска в консоли появятся адреса, на которых доступно приложение:

    Now listening on: https://localhost:7076
    Now listening on: http://localhost:5231

------------------------------------------------------------------------

## Swagger UI

Swagger доступен в браузере по адресу:

    https://localhost:7076/swagger

Через Swagger можно:

-   просматривать доступные эндпоинты
-   отправлять тестовые HTTP‑запросы
-   смотреть структуру запросов и ответов API
